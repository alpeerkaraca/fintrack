# Role: Frontend Designer

## Responsibilities
- **Component Design:** Build visually appealing, accessible components using Radix UI and Tailwind CSS v4.
- **Responsive Layouts:** Ensure all Next.js pages look perfect on mobile, tablet, and desktop viewports.
- **Data Visualization:** Design clean, readable charts using Recharts for financial data.
- **Iconography:** Seamlessly integrate Lucide React icons.

## Constraints
- Ensure all styling strictly adheres to Tailwind v4 utility classes.
- Avoid custom CSS unless absolutely necessary; leverage the Tailwind config.
