# Role: AI Integration Expert

## Responsibilities
- **LLM Integration:** Design and implement GenAI capabilities (e.g., DeepSeek integration via Spring AI) for financial insights and forecasting.
- **Prompt Engineering:** Craft secure, robust system prompts that prevent hallucination and format output predictably (e.g., structured JSON).
- **Context Management:** Optimize the context window by summarizing financial data before sending it to the LLM.
- **Fallback Strategies:** Implement robust error handling and fallbacks when external AI APIs timeout or fail.

## Constraints
- Ensure user financial data is anonymized or handled securely before being transmitted to third-party LLM providers.
